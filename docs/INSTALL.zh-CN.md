# 安装 WordNest

[English](INSTALL.md) · 简体中文

WordNest 免费开源。首个发行版本使用 **ad-hoc 临时签名，未经 Apple Developer ID 签名或公证**；自行编译不需要付费的 Apple 开发者会员。临时签名用于本地代码完整性校验，不代表 Apple 已确认开发者身份或检查应用安全性。请仅从[官方仓库的 Releases](https://github.com/Albort12138/WordNest/releases) 下载。[26.1.0（build 1）](https://github.com/Albort12138/WordNest/releases/tag/v26.1.0) 是首个公开试用版，全新环境安装及其他 Mac 配置仍待验证。

## 系统要求与校验

需要 Apple Silicon Mac、macOS 14 或更新版本，暂不提供 Intel 安装包。下载以 `-unnotarized.dmg` 结尾的 DMG、对应的 `-SHA256SUMS.txt`，也可下载 `-build-info.txt` 核对构建信息。ZIP 是包含同一应用和文档的替代包。

在终端进入下载目录，计算 DMG 的校验和（请按实际下载文件名调整）：

```sh
shasum -a 256 WordNest-26.1.0-build1-macos-arm64-unnotarized.dmg
```

将完整结果与发行页校验文件中同名文件的值比较。校验和可发现下载损坏，但不能独立证明发布者身份，也不代表应用已经通过安全审查。

## 安装与首次启动

1. 更新前先退出正在运行的 WordNest。打开 DMG，将 **WordNest.app** 拖入 **应用程序**；确认更新时替换旧版，然后推出 DMG。
2. 从 **应用程序 → WordNest** 启动。请为安装后的这一份应用授权。
3. macOS 可能提示无法检查应用或无法验证开发者。如果你信任这次下载，请按 [Apple 针对单个应用的官方流程](https://support.apple.com/zh-cn/102445)操作：先尝试启动，再打开 **系统设置 → 隐私与安全性**，在右侧向下滚过权限列表，到 **安全性** 区域找到 WordNest 的拦截提示，若提供 **仍要打开**，点击并在后续提示中确认打开。系统可能要求管理员验证；不同系统版本和受管理的 Mac 表现可能不同，不保证总能提供此入口。
4. 如果提示含有恶意软件、授权被撤销或应用已损坏，请停止操作，核对下载并反馈完整提示，不要将所有警告都当作“未知开发者”。
5. WordNest 的首个页面会让你选择语言，默认 **跟随系统**。之后按所需功能完成权限引导。

不需要也不建议关闭 Gatekeeper／SIP、修改全局安全策略或移除隔离属性。若没有针对单个应用的例外入口，可以审阅源码后自行编译，或反馈系统环境与提示。

## 权限与更新

屏幕录制用于本机截图识别；备忘录自动化用于收藏和读取生词；Safari 自动化与辅助功能用于支持的窗口中的可选来源获取。这些权限与“仍要打开”相互独立，必须由你亲自授权。

授权后若系统要求“退出并重新打开”，按提示操作。如果系统只退出而未重启，请再次打开同一份已安装应用，继续之前的设置步骤。ad-hoc 签名会随构建变化，更新后可能需要重新授予隐私权限。保持安装位置一致，功能不可用时从 WordNest 的设置中检查，不要重置全系统权限。安装更新本身不会删除 Apple 备忘录中的生词。

暂不支持自动更新；下载新版后，先退出应用再替换。自行编译步骤见 [README](https://github.com/Albort12138/WordNest/blob/main/README.zh-CN.md#从源代码构建)。
